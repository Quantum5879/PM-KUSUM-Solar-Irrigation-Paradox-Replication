# PM-KUSUM Solar Irrigation Paradox — Replication Package

Replication materials for:

> Dagar, H., & Bhandari, G. *Do Subsidised Solar Pumps Really Cut Carbon or Shift the Cost to Groundwater? Evidence from India's PM-KUSUM.* Submitted to *Energy Policy*.

This repository contains the processed state–year panel, raw inputs used by the pipeline, configuration files, estimation scripts, and result tables needed to reproduce the paper’s findings.

## Contents

| Path | Description |
|------|-------------|
| `data/processed/master_panel_state_year.parquet` | Main analysis panel (36 states/UTs × 11 fiscal years) |
| `data/processed/*.csv` | Carbon ledger, groundwater assessment years, data dictionary |
| `data/raw/` | Ingested administrative CSVs + India state boundary GIS |
| `config/` | Parameter grids, literature defaults, state-name map |
| `scripts/p3_00`–`p3_15` | Full estimation and figure pipeline |
| `scripts/build_*.py` | Document builders (optional) |
| `outputs/tables/` | Estimation result CSVs used in the manuscript |
| `outputs/figures/executive/` | Executive visuals (PNG, 400 dpi) |
| `run_all.py` | One-command reproduction entry point |

## Quick start

```bash
# Python 3.10+ recommended
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
# source .venv/bin/activate

pip install -r requirements.txt
python run_all.py
```

Seed is fixed at **1502** throughout.

Optional for map figure V2: `geopandas` and `pyogrio` (already listed in `requirements.txt`).

## Key results regenerated by the pipeline

- TWFE / wild-bootstrap channel estimates (`outputs/tables/fe_channel_results.csv`)
- IV battery and placebos (`outputs/tables/iv_results.csv`, `iv_reduced_form_placebos.csv`)
- Carbon gross / rebound / net bridge (`outputs/tables/decomposition_by_stress.csv`)
- Adversarial confirmation suite (`outputs/tables/critical_*.csv`)
- Executive SI visuals under `outputs/figures/executive/`
